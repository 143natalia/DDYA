# Semana 1
Respuestas para la prueba diagnostica. Como tal, esta prueba constaba de 4 partes: 
1. Un primer codigo condicional sencillo para determinar si un número dado por el usuario es positivo, negativo, o cero.
2. Añadir al codigo anterior otras dos funciones: una para determinar si el número dado es parte de la Secuencia Fibonacci, y otro para determinar si el número es primo.
3. Diseño de un diagrama de flujo que explique el codigo anterior en su totalidad
4. Un algoritmo basado en un pseudocodigo que, con una sola linea de información sobre estudiantes y sus notas, organizarla en una lista y luego mostrar cuales estudiantes están por encima del promedio.
En la carpeta encontrarán solo dos archivos, debido al hecho de que no logré pensar en una solución a algunos de los problemas del algoritmo a tiempo.
Tampoco conseguí terminar la primera parte, especificamente lo relacionado a los números primos. Mis soluciones fueron hechas con cadenas de ifs y un if dentro de un while loop.
El diseño del diagrama de flujo se basa en la explicación de clase hoy.Aún así, no estaba segura de como representar un loop while.
